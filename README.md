# Rebecca - Portfolio & KCA University Attachment Application Suite

A modern React + TypeScript portfolio and official industrial attachment application suite for **Rebecca**, an Information Technology student at **KCA University** (Student Reg. No: `2502692`).

## Key Features

- **KCA University Attachment Application Suite**:
  - Official, formal industrial attachment application letter addressed to KCA University Directorate of ICT Services.
  - Tailored Curriculum Vitae (CV) emphasizing hardware diagnostics, computer lab maintenance, networking, Linux systems administration, and student IT support.
  - One-click print-to-PDF formatting (academic standard layout, header, and typography).
  - Quick clipboard copy for Microsoft Word or email dispatch.
  - Real-time personalization for recipient title, contact details, and dates.
- **Academic Qualifications & Coursework**:
  - KCA University Diploma in IT records (Web Development A, Computer Architecture A, Database Systems A-, Operating Systems B).
  - Current studies overview (Java, Network Design, Application Programming, Data Structures).
- **Featured Projects**:
  - *Perfume Store*: Live e-commerce website with WhatsApp API checkout.
  - *Car Showcase*: Multi-device responsive automotive catalog.
  - *Tech Portfolio*: Fast, accessible web application.
- **Documents & Credentials**:
  - In-app interactive preview modal and direct download links for Curriculum Vitae (`CV.pdf`), Professional Resume (`Resume.pdf`), and Cover Letter (`Cover_Letter.pdf`).
- **Interactive Contact**:
  - Student email (`2502692@students.kcau.ac.ke`), phone (`0116968755`), LinkedIn, and GitHub links.

## Tech Stack

- **Framework**: React 19, TypeScript
- **Bundler / Server**: Vite (running on `0.0.0.0:3000`)
- **Icons**: Lucide React
- **Styling**: Modern CSS with dark glassmorphism aesthetic and dedicated `@media print` styling for formal paper documents.
